# Pfizer: AI-Powered Document Insights and Data Extraction

**Timeline:** October 2026 - Present

## Summary

An AI-powered system that extracts key information from pharmaceutical documents, helping compliance teams review files faster and catch issues before they get buried.

## Context / Problem

Pharmaceutical compliance teams review large volumes of documents every day: vendor certificates, compliance bulletins, quality reports. These files can run past 100 pages and are often reviewed line by line, which is slow, costly, and error-prone.

The stakes became clear during COVID-19. Pfizer and BioNTech delivered the first FDA-authorized COVID-19 vaccine in under a year[^1], and every batch needed a paper trail proving it was safe[^2]. When documentation slows down, so does getting treatments to patients.

The challenge is that these documents are unstructured. Many are scanned images, layouts vary from file to file, and key details like expiry dates are buried in the text. Missed information can mean missed deadlines or overlooked compliance risks. AI can help by reading, organizing, and flagging this information automatically.

## Goal / What the System Will Do

I'm building a system that will:

- Extract key data, such as dates and vendors, from PDFs and scanned documents
- Classify document types
- Flag compliance risks
- Let users search and ask questions in plain language through a chatbot
